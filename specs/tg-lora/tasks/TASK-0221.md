## 実装内容

`tests/test_freeze_validloss_ci_9b_resume.py` に 3 テスト + 1 ヘルパーを追加（src/scripts 変更ゼロ）:

1. `_cfg_section_reads(source, section)` — AST スキャンで `cfg.<section>` からの字段読み取りを 3 形式すべて捕捉（`cfg.training.X` / `cfg.training.get("X")` / `cfg.get("training", {}).get("X")`。コメント・docstring・文字列リテラルは AST により自然に無視）。

3. `test_fingerprint_completeness_every_consumed_training_field_covered` — cache 側 block 4 の ledger 版。launcher + `src/model/load_model.py` の実ソースをスキャンした消費面 = {`trainable_lora_scope`→`scope_label`, `learning_rate`→`learning_rate`（指紋化）} ∪ {`max_steps`（footer ラベルのみ・arm bytes 不変）, `gradient_checkpointing`（メモリ専用・numerics 同一）}（allow-list・理由付き）を**等値で** pin。将来 `weight_decay` 等の新ノブが arm path に配線されたら指紋化か正当化を要求し失敗する（omission 検知）・指紋 key の drop も検知・allow-list のスキーマ漂移も検知（双方向）。
